# PythonGame2024
Python text adventure game</br>
remake is being planned

Needed:</br>
  Python3</br>
  cmd
  
Start:</br>
python main.py in cmd to play the game

Game idea: </br>
Find necessary items to help you leave the place.

Plan was to have </br>
info, areas, items,input validation, main </br>
as their separate python files.

In the end:</br>
Game is in Main</br>
Info has area and moving between them</br>
Items have inventory and actions related to them</br>
Lore has all story related text</br>
Game has player input validation and game ending.</br>

Used:</br>
Functions,</br>
List, dict,</br>
if-else,</br>
try-except</br>
