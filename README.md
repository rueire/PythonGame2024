# PythonGame
Python text adventure game 2024</br>
UPDATED 2025

### Needed:</br>
  Python3</br>
  cmd
  
### Start:</br>
Run the game by opening a command prompt in desired dir (Game2024 or Game2025) and executing:<br>
```python main.py``` <br>
No external libraries are required — the game uses only basic Python features.

### Game idea: </br>
Figure out map and find items to help you leave the place.
